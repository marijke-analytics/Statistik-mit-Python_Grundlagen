# 📊 Statistik mit Python – Grundlagen

Dieses Repository enthält kompakte, praxisnahe Beispiele zu grundlegenden statistischen Methoden mit Python.  
Ideal für Einsteiger*innen, die Statistik Schritt für Schritt anhand klarer, verständlicher Beispiele lernen möchten.

## 📚 Inhalte
- Deskriptive Statistik (Lagemaße, Streuung, Konzentration)
- Wahrscheinlichkeitsrechnung & Zufallsvariablen
- Verteilungen (Binomial, Hypergeometrisch, Normal)
- Lineare Regression & Korrelation
- Zeitreihenanalyse (Trend, Prognose, Glättung)
- Bestandsanalyse
- Grafische Darstellung statistischer Daten

## 🧰 Verwendete Libraries
- `pandas`
- `numpy`
- `matplotlib`
- `seaborn`
- `scipy`
